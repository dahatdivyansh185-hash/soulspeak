# SoulSpeak

A premium midnight-themed landing page for SoulSpeak — an anonymous emotional social platform.

## Features
- Cinematic intro animation
- Midnight glassmorphism UI
- Animated starry background and parallax motion
- Responsive layout optimized for mobile and desktop
- PWA support with `manifest.webmanifest` and `service-worker.js`
- Anonymous community storytelling experience

## Run locally
Open `index.html` in a browser or serve the folder with a static server.

## Files
- `index.html` — landing page structure
- `styles.css` — visual design, gradients, and animations
- `script.js` — intro sequence, parallax, counters, and PWA registration
- `manifest.webmanifest` — PWA metadata
- `service-worker.js` — asset caching for offline support
- `icons/icon.svg` — app icon
